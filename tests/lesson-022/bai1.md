##Bài 1: Giải thích công dụng của các lệnh

- git init => tạo ra 3 vùng: working directory, staging area và repository cho một folder đang mở.
- git add => đưa file đã tạo trong vùng working directory lên staging area.
- git add . => đưa tất cả các file đã tạo trong vùng working directory lên staging area.
- git commit -m “message” => đưa file đã add trong vùng staging area lên repository, cùng với "message" chứa nội dung đã mình làm gì với commit này.
